# alu-regex-data-extraction_amudaheranwa

# Project Description

This project is a Python program that uses Regex to extract information from a raw messy text

The raw text is meant  to represent realistic data that can be gotten from an API or collected from somewhere random. The program searches the text for valid email addresses, URLs, phone numbers, and credit card numbers.

The program also checks the input for unsafe content and ignores obvious malicious content such as script tags and JavaScript links. Credit card numbers are masked before they are saved to the output file.

#The Data Types Extracted from the 8 we were to chose to select from

The program extracts four main types of data:

1. Email addresses
2. URLs
3. Credit card numbers
4. Phone numbers
